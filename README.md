# Circuit Start

Act as an expert frontend developer and UI/UX designer.

Build a complete, modern, responsive frontend website for an Embedded Systems and Electronics learning platform.

IMPORTANT:

For now, create ONLY the frontend.

Do not create a backend, database, authentication system, payment system, or API integration.

Use realistic static/dummy data wherever necessary.

The main purpose of this website is to help beginners understand Embedded Systems and basic Electronics in a simple, structured, and visually engaging way.

The website should feel like a combination of:

- An Embedded Systems learning platform

- An Electronics education website

- A Professional technology portfolio

TARGET USERS:

- Complete beginners

- School students

- College students

- Engineering students

- Electronics hobbyists

- Anyone who wants to start learning Embedded Systems

MAIN USER EXPERIENCE:

When a user visits the website, they should clearly understand:

1. What Embedded Systems are

2. Where Embedded Systems are used

3. Basic Electronics concepts

4. Important electronic components

5. Essential Embedded Systems tools

6. Which learning path to follow

7. How to start building simple mini projects

DESIGN STYLE:

Create a futuristic and professional electronics-themed interface.

Use:

- Dark theme as the main design

- Black, dark gray, and deep navy backgrounds

- Electric blue and cyan accent colors

- Optional subtle neon green highlights

- Circuit board inspired background elements

- PCB lines and electronic node patterns

- Microchip and technology-inspired visuals

- Modern card-based layout

- Clean spacing

- High-quality typography

- Smooth hover effects

- Subtle animations

- Glassmorphism only where it improves the design

The design should look modern and premium, but it must not feel overcrowded or overly complicated.

The entire website must be fully responsive for:

- Desktop

- Tablet

- Mobile
